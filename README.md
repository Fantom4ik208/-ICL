## 🚨 Известные проблемы (Known Issues & Bugs)

> ⚠️ **ВНИМАНИЕ:** Обнаружены критические ошибки, влияющие на стабильность и безопасность.

### 🔴 Критические (Critical)
1. **Нехватка места на системном диске:** Свободно всего `29.4 ГБ`. Из-за этого падают обновления Windows (Ошибка `0x80070070`).
2. **Конфликт имён NetBIOS:** Имя `DESKTOP-H17KU8I` конфликтует с множеством устройств в подсети `192.168.20.x` (ошибки `4321`, `2505`).
3. **Не активирована Windows:** Ошибка `0x80004005` при каждом входе.
4. **Уязвимость безопасности:** Основная учётная запись `User` не имеет пароля. Secure Boot отключен.

### 🟡 Средние (Major)
1. **Нехватка памяти для SQL Server:** Ошибка `701` (Out of Memory) от 28.09.2026.
2. **Падение PostgreSQL:** Служба `postgresql-x64-17` и `pg_ctl.exe` неожиданно прерываются.
3. **Ошибки оборудования (WHEA):** Зафиксированы устранимые аппаратные ошибки (26.09.2026).
4. **Проблемы с Bluetooth:** Тайм-ауты адаптера Realtek 8821CU.

## 📋 План работ (Roadmap / To-Do)

- [ ] **Срочно:** Очистить диск `C:` (WinSxS, Temp, старые бэкапы) или заменить SSD на 512 ГБ+.
- [ ] **Сеть:** Переименовать ПК или отключить NetBIOS over TCP/IP для устранения конфликтов.
- [ ] **Безопасность:** Установить пароль на учётную запись `User` или перейти на использование `IT-user`. Включить Secure Boot в BIOS.
- [ ] **БД:** Настроить `max server memory` для MSSQL, чтобы избежать OOM. Проверить логи PostgreSQL.
- [ ] **ОС:** Выполнить активацию Windows (KMS / Корпоративная лицензия).
- [ ] **Железо:** Обновить BIOS (текущий от 2021 года). Провести стресс-тест для проверки ошибок WHEA.
- [ ] **Драйверы:** Обновить драйверы Realtek Bluetooth и Wi-Fi.
